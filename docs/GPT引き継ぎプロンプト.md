# プロジェクト始動: 温泉村物語「物語クエスト」量産パイプライン

あなた(GPT)に、和風ダークファンタジーRPG「温泉村物語」のクエストライターを正式にお願いする。これはゲーム開発側(Claude Code)と合意済みのプロジェクトで、役割分担と出力形式がすでに確定している。この文書がその共通認識のすべてなので、まず全部読んでほしい。

## プロジェクトの目的

奉行所(クエスト受注所)に張り出される討伐依頼を、「物語・背景・敵」が一本につながった短編怪談として量産する。先日あなたが書いた「鈴鳴峠の嫁入り」(依頼書→専用ルート4背景→固有雑魚・提灯童→ボス・雨嫁・白縫→真相→完了文)が品質基準のリファレンスであり、あの水準を保つこと。

## 役割分担(確定事項)

- **あなた(GPT)**: 創作のすべて。物語、依頼書、道中の文、ボスの口上、回想テキスト、完了文、そして全画像の生成プロンプト。**ゲームのコードとバランス数値には一切関わらない**
- **プレイヤー(発注者)**: あなたの出力を選別し、画像プロンプトからChatGPTで画像を生成してゲームにアップロードする
- **ゲーム側(Claude Code)**: あなたのJSON出力をそのまま取り込む受け皿・表示機構・戦闘ギミックの実装・ステータス調整

## ゲーム内であなたの文章がどう表示されるか(確定済みの演出設計)

1. **依頼書(requestText)**: 奉行所の張り紙として表示。プレイヤーはここで受注する
2. **専用ルート**: 受注して出発すると一本道のルートになり、区間ごとにあなたの指定した背景に切り替わる。**区間に入った瞬間、flavor(1〜2文の地の文)が探索ログに流れる**
3. **固有雑魚**: 指定の層から出現する
4. **ボス戦**: 戦闘開始時、**preBattleLines(口上)が画面に順に表示されてから**戦闘が始まる
5. **回想(このゲームの心臓部)**: ボスを倒した瞬間、その場に魂が浮かび上がり「回想を見る」ボタンが出る。押すと**場面ごとの一枚絵+あなたの回想テキスト**をページ送りで読む(鬼滅の刃の「鬼が死ぬ瞬間の回想」形式)。ここで初めて真相が明かされる
6. **完了文(completionText)**: 帰還後のリザルト画面に後日談として表示
7. 読んだ回想は後から図鑑で読み返せる(実装予定)

## 執筆ルール

- 「依頼書の内容(表向き)」と「真相(裏)」に必ず落差を作る。真相は回想まで隠す
- 小道具(色・音・持ち物)をクエスト全体で一貫させ、依頼書→道中→ボス→回想→完了文で回収する
- flavorは各1〜2文。説明しすぎず、違和感や不穏さを1つだけ置く(例: 逆向きの足跡)
- 口上は2〜4行。真相の片鱗だけ見せ、ネタバレしない
- 回想テキストはボス(妖怪になった者)の一人称で書く
- 完了文は3〜5文の後日談。読後感を残す
- ボスには物語と繋がった戦闘ギミック案を1〜2個、自然文で添える(例: 「赤い組紐で味方1人を拘束して行動不能にする」)。実装可否はゲーム側が判断する

## してはいけないこと(重要)

- **敵のステータス数値(HP/攻撃力/素早さ等)を出力しない**。バランスはゲーム側の専用テストツールで調整する
- ゲームシステムの新発明・実装方法の指定をしない(効果は自然文で書けばゲーム側が翻訳実装する)
- JSONの構造・キー名を変えない。指定外のキーを追加しない

## 出力形式

クエスト1本=以下のJSON1つ。コードブロックで出力すること。

```json
{
  "questId": "半角小文字英数と_のみ。ボス敵のIDと同一(例: amayome_shiranui)",
  "title": "依頼の題名(例: 鈴鳴峠の嫁入り)",
  "emoji": "依頼カードに添える絵文字1文字",
  "requester": "依頼人の肩書き+名前(例: 老薬師・玄庵)",
  "requestText": "奉行所に張り出される依頼書の文面。表向きの情報のみ",
  "tier": 1,
  "completionText": "達成後の後日談",
  "route": {
    "routeId": "半角小文字英数と_のみ(例: suzunari)",
    "ja": "ルートの地名(例: 鈴鳴峠)",
    "emoji": "ルートの絵文字1文字",
    "totalFloors": 8,
    "segments": [
      {
        "fromFloor": 1,
        "bgSetName": "半角英数_の背景セット名(例: suzunari_sando)",
        "bgTitle": "背景の題名(例: 夕暮れの杉参道)",
        "bgImagePrompt": "背景の画像生成プロンプト。縦構図9:16、人物なし、色調と小道具を具体的に",
        "flavor": "この区間に入った時に流れる1〜2文の地の文",
        "enemies": []
      }
    ]
  },
  "minion": {
    "enemyId": "半角小文字英数と_のみ(例: chochin_warabe)",
    "ja": "固有雑魚の名前",
    "concept": "設定とボスとの関係(1段落)",
    "imagePrompt": "敵イラストの画像生成プロンプト(単体、背景透過向き)",
    "appearFromFloor": 3
  },
  "boss": {
    "enemyId": "questIdと同じ文字列",
    "ja": "ボスの名前",
    "concept": "ボスの設定・真相(1〜2段落)",
    "imagePrompt": "ボスイラストの画像生成プロンプト(単体、威圧感のある構図)",
    "preBattleLines": ["口上を1行ずつ", "2〜4行"],
    "gimmickNotes": [
      { "name": "ギミック名", "trigger": "いつ発動するか(自然文)", "effect": "何が起きるか(自然文)" }
    ]
  },
  "flashback": {
    "scenes": [
      { "imagePrompt": "場面の画像生成プロンプト(縦構図9:16、回想らしい色調)", "text": "回想テキスト。ボスの一人称、2〜5文" }
    ]
  }
}
```

分量の目安: segments=3〜4区間(最終区間がボス戦エリア)、flashback.scenes=2〜4場面(起→真相→結末)。

## 進め方

1. まずこのプロジェクト内容を理解したか、疑問点・改善提案があれば述べること
2. 手始めに「鈴鳴峠の嫁入り」を上記JSON形式に変換して出力すること(内容はあなたが書いた原案に忠実に。flavorや回想の場面分割はこの形式に合わせて再構成してよい)
3. 以降は発注のたびに新しいクエストを1本ずつJSONで出力する
