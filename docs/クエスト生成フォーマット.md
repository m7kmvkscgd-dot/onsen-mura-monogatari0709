# クエスト生成フォーマット(GPT/Codex用の出力契約書)

この文書は、物語生成AI(GPT等)に「奉行所クエスト一式」を出力させる時のプロンプトに貼る仕様書です。
ゲーム側(温泉村物語)はこのJSONをそのまま取り込める受け皿を持っているため、**この形式に従っていれば、生成されたクエストは手直しなしでゲームに入ります**。

## AIへの指示(この節ごとプロンプトに貼る)

あなたは和風ダークファンタジーRPG「温泉村物語」のクエストライターです。以下のルールで、クエスト1本ぶんを**1つのJSON**として出力してください。

### 世界観・文体のルール
- 舞台は和風の山里。妖怪は怪談の存在で、多くは悲劇や未練から生まれている
- 「依頼書の内容(表向き)」と「真相(裏)」に落差を作ること。真相は回想(flashback)で初めて明かされる
- 小道具(色・音・持ち物など)をクエスト全体で一貫させ、依頼書→道中→ボス→回想→完了文で回収すること
- 道中のフレーバーは各1〜2文の地の文。説明しすぎず、違和感や不穏さを1つだけ置く
- ボスの戦闘前の口上は2〜4行。真相の片鱗だけ見せ、ネタバレはしない
- 回想(flashback)のテキストはボス(妖怪になった者)の一人称で書く
- 完了文は依頼解決の後日談を3〜5文で。読後感を残すこと

### してはいけないこと
- **敵のステータス数値(HP/攻撃力等)を出力しない**(バランス調整はゲーム側の仕事)
- ゲームシステムの新発明をしない(効果の説明は自然文でよい。実装はゲーム側が行う)
- JSONの構造・キー名を変えない。指定のない追加キーを作らない

### 出力JSONの構造

```json

  "questId": "半角小文字英数と_のみ。ボス敵のIDと同一になる(例: amayome_shiranui)",
  "title": "依頼の題名(例: 鈴鳴峠の嫁入り)",
  "emoji": "依頼カードに添える絵文字1文字",
  "requester": "依頼人の肩書き+名前(例: 老薬師・玄庵)",
  "requestText": "奉行所に張り出される依頼書の文面。表向きの情報のみ",
  "tier": 1,
  "completionText": "クエスト達成後の後日談(リザルト画面に表示)",
  "route": {
    "routeId": "半角小文字英数と_のみ(例: suzunari)",
    "ja": "ルートの地名(例: 鈴鳴峠)",
    "emoji": "ルートに添える絵文字1文字",
    "totalFloors": 8,
    "segments": [
      {
        "fromFloor": 1,
        "bgSetName": "背景セット名。半角英数_(例: suzunari_sando)",
        "bgTitle": "背景の題名(例: 夕暮れの杉参道)",
        "bgImagePrompt": "この背景の画像生成プロンプト。縦構図(9:16)、人物なし、指定の色調・小道具を含む詳細な英語または日本語",
        "flavor": "この区間に入った時に流れる1〜2文の地の文",
        "enemies": []
      }
    ]
  },
  "minion": {
    "enemyId": "半角小文字英数と_のみ(例: chochin_warabe)",
    "ja": "固有雑魚の名前(例: 提灯童)",
    "concept": "この雑魚の設定・ボスとの関係(1段落)",
    "imagePrompt": "敵イラストの画像生成プロンプト(単体・背景透過向きの構図)",
    "appearFromFloor": 3
  },
  "boss": {
    "enemyId": "questIdと同じ文字列にする",
    "ja": "ボスの名前(例: 雨嫁・白縫)",
    "concept": "ボスの設定・真相(1〜2段落)",
    "imagePrompt": "ボスイラストの画像生成プロンプト(単体・威圧感のある構図)",

      { "name": "ギミック名", "trigger": "いつ発動するか(自然文)", "effect": "何が起きるか(自然文)" }
    ]
  },

    "scenes": [
      {
        "imagePrompt": "この場面の画像生成プロンプト。縦構図(9:16)、回想らしい色調",
        "text": "この場面の回想テキスト。ボスの一人称、2〜5文"
      }
    ]
  }
}
```

### 分量の目安
- route.segments: 3〜4区間(最後の区間がボス戦エリア)
- flashback.scenes: 2〜4場面(起→真相→結末の順)
- boss.gimmickNotes: 1〜2個(物語と繋がった戦闘ギミック。例: 組紐で味方1人を拘束する)

---

## ゲーム側の取り込みルール(Claude用メモ。GPTには関係ない)

- questId=ボスのenemyId=QUEST_DEFSのキー(討伐依頼は敵IDをキーにする既存規約)
- route→QUEST_ROUTE_DEFS[routeId](segments.bg=bgSetName、flavorは区間フレーバー表示へ)。QUEST_DEFS側にroute/targetFloor(=totalFloors)を設定
- minion/boss→ENEMIESへ新規追加(questOnly:true+maxFloor:0、ステータスはClaude/ユーザーがボステストで調整)。boss.preBattleLines→ENEMIES[boss].preBattleLines、flashback→ENEMIES[boss].soulStory.scenes(imageは画像が来たらassets/story/へ)
- gimmickNotes→ENEMIES[boss].gimmickNotesに転記し、Claudeがgimmicks(構造化データ)へ翻訳実装→ボステストで検証
- 画像: 背景はエディタの「背景セット預かり所」経由(昼1枚でOK運用)。敵絵・回想絵はユーザーがChatGPTで生成→アップロード。**画像が未提供でもクエストは動く**(背景=森で代用、敵絵=近い既存絵で暫定、回想=テキストのみ表示)
- 報酬(rewardGold等)・敵ステータス・出発可能時間はJSONに含めない=ゲーム側で決める
